## 📊 What is ResearchOS?

AI-powered research automation platform combining:
- **SocialX-style** big data analytics
- **Claude AI agents** for research design & insights
- **Automated report generation** (paper-ready PDFs)

### Use Cases
- University researchers (80% time savings)
- Startups (market research automation)
- Agencies (consumer insights)
- Policy makers (social analysis)

### Pricing
- **Basic:** $50/mo (students)
- **Pro:** $200/mo (individual researchers)
- **Team:** $500/mo (research groups)
- **Enterprise:** $2K+/mo (universities)

## 🛠️ Tech Stack

- **Frontend:** Next.js 16 + React 19 + TypeScript + Tailwind + Shadcn/ui
- **Backend:** Express.js + TypeScript + Zod
- **Database:** Supabase (PostgreSQL) + RLS
- **AI:** Claude API + Hermes agents
- **Auth:** NextAuth.js + Google OAuth
- **Deployment:** Vercel (frontend) + VPS (backend)
